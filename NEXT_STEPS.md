# What to Build First

Follow this order:

1. Create the React frontend.
2. Create the Express backend.
3. Connect MongoDB.
4. Add 10 sample products.
5. Build `/api/products`.
6. Display products in React.
7. Build the chatbot UI.
8. Build `/api/chat`.
9. Connect Gemini/OpenAI.
10. Make AI search the MongoDB products.
11. Add product comparison.
12. Improve the UI.

## Important

Do not start with advanced features.

First make this work:

User message → AI understands request → MongoDB finds products → UI displays recommendations.

After that, add wishlist, cart, login, voice, and other features.
