# Features

## 1. AI Shopping Chat
Examples:
- Show phones under ₹20000.
- I need a laptop for coding.
- Suggest gaming headphones.
- Which product is best?

## 2. Product Search
Filter by:
- Category
- Price
- Brand
- Rating
- Features

## 3. AI Recommendation
The chatbot recommends suitable products and briefly explains why.

## 4. Product Comparison
Compare two or more products by:
- Price
- Rating
- Features
- Brand

## 5. Product Cards
Each card should show:
- Image
- Product name
- Price
- Rating
- Short description
- View button
- Compare button
