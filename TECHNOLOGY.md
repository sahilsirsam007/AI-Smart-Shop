# Technology Stack

## Frontend
### React.js
Used to create the chatbot interface and product cards.

### Tailwind CSS
Used for simple responsive styling.

## Backend
### Node.js
Runs the server.

### Express.js
Creates REST APIs.

## Database
### MongoDB
Stores products and optional chat/user data.

## AI
Use either:
- Google Gemini API
- OpenAI API

The AI understands natural-language shopping requests and helps generate recommendations.

## Optional
JWT authentication can be added later.
